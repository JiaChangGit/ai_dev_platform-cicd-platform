# 虛構裝置事件匯出閱讀筆記

本筆記把 `sample-spec.md` 的句子轉成可測試行為。它只處理已寫明的要求；規格未定義的行為列在疑問區。

採用版本：`SAMPLE-EVENT-EXPORT 1.0`。若 `source-register.md` 的版本改變，本筆記與手冊必須在同一個 PR 重新核對。

| 需求 | 可確認的行為 | 最小驗收案例 | 狀態 |
|---|---|---|---|
| REQ-001 | 每筆事件一行；UTF-8；四欄順序固定 | 輸入一筆事件，比對完整輸出 bytes | 已確認 |
| REQ-002 | sequence 遞增排列 | 輸入 sequence 3、1、2，預期 1、2、3 | 已確認 |
| REQ-003 | 未知 code 不得丟失；message 固定為 `UNKNOWN` | 輸入未登記 code `0x9f`，比對 code 與 message | 已確認 |

## 待確認

- sequence 重複時是否維持輸入順序？
- sequence 換回零時，用模數順序還是一般整數順序？
- message 含換行字元時，要跳脫、截斷或拒絕？

這三題沒有對應需求文字，不能從 REQ-001～REQ-003 推論答案。實作前應由規格負責人補充規格或留下 ADR。
