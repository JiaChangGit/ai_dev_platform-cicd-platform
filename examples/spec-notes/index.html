裝置事件匯出教學手冊

虛構範例：本頁不代表任何標準或產品規格；用途是示範如何把規格整理成可追溯的教學文件。

先讀輸入與輸出

輸入是一組裝置事件；輸出是一組適合人員閱讀與工具比對的 UTF-8 文字列。先保留規格已定義的欄位與順序，不加入推測的轉換。

需求對照

需求實作重點驗收方式
REQ-001每筆一行，欄位依 sequence、level、code、message 排列。比對 UTF-8 bytes 與完整欄位順序。
REQ-002輸出依 sequence 遞增。以 3、1、2 的輸入驗證輸出為 1、2、3。
REQ-003未知 code 原樣保留，message 為 UNKNOWN。輸入未登記 code，確認 code 未遺失。

不得自行補寫的行為

  • sequence 重複時的先後順序。
  • sequence 換回零時的比較方式。
  • message 含換行字元時的處理方式。

以上條件都應標記為待確認，由規格負責人補充需求或由團隊留下決策紀錄。
