# 虛構裝置事件匯出規格

本文件只供平台範例測試，不是任何標準或產品規格。

## REQ-001：輸出格式

工具應將每筆事件輸出為一行 UTF-8 文字，欄位順序為 sequence、level、code、message。

## REQ-002：排序

同一份輸出中的事件應依 sequence 由小到大排列。

## REQ-003：未知事件

工具遇到未登記的 code 時，應保留原始 code，並將 message 顯示為 `UNKNOWN`。

## 未定義項目

規格沒有定義 sequence 重複或換回零時的排序方式，也沒有定義 message 是否可能包含換行字元。實作者必須先取得決策，不得自行假設。
