# Issue 模板

複製以下內容建立新 issue：

```markdown
## 摘要
（一句話描述問題或需求）

## 類型
- [ ] Bug
- [ ] Feature
- [ ] 技術債 / Refactor
- [ ] 文件

## 詳細描述
（Bug：預期行為 vs 實際行為；Feature：使用者故事）

## 重現步驟（Bug 適用）
1.
2.
3.

## 環境資訊（Bug 適用）
- 版本：
- 平台/環境：
- 相關 log：

## 領域背景（如適用）
（若此 issue 涉及特定產品領域的慣例或限制，附上參考來源；見 `docs/domain-adaptation.md`）

## 驗收標準
- [ ]
- [ ]

## 相關連結
（相關 PR、ADR、外部文件）
```
